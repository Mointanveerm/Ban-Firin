Ban Firin Bakers — static website

Upload EVERY file in this folder to your hosting root
(public_html, www, or htdocs). Keep them together in the same folder:

  index.html
  styles.css
  script.js
  favicon.svg
  butter-biscuits.jpg
  khatai.jpg
  packaging.jpg

Do not upload only index.html — the photos and styles live next to it.
No Node, no install, no rotating cookie. Open index.html in a browser
or point your domain at this folder.
